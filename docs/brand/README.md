# Фирменные материалы ТЕТА для макетов и документов

> Версия 2.0 · 11.09.2026 · Основание: указания заказчика от 11.09.2026 ([DEC-02, DEC-03, DEC-04](../01_inputs/decisions_v2.md)).

## Логотип

Используются **только файлы заказчика**. Логотип не перерисовывается, не набирается шрифтом, не перекрашивается и не стилизуется.

| Файл | Что это | Где применять |
|---|---|---|
| [teta_logo_on_white.jpg](teta_logo_on_white.jpg) | Оригинал заказчика: чёрный логотип на белом фоне (`teta_info/новое лого white.jpg`) | Печать, документы на белом фоне |
| [teta_logo_on_black.jpg](teta_logo_on_black.jpg) | Оригинал заказчика: белый логотип на чёрном фоне (`teta_info/новое лого black.jpg`) | Тёмные носители |
| [teta_logo_black.png](teta_logo_black.png) | Чёрный логотип с прозрачным фоном — из оригинала на белом фоне; фон удалён, форма не менялась | Светлые интерфейсы, HTML-сводка, DOCX |
| [teta_logo_white.png](teta_logo_white.png) | Белый логотип с прозрачным фоном — из оригинала на чёрном фоне | Тёмные интерфейсы, фиолетовые и графитовые плашки |

В именах исходных файлов заказчика цвет обозначает фон: `новое лого black.jpg` — белый логотип на чёрном фоне, `новое лого white.jpg` — чёрный логотип на белом фоне.

Векторные версии логотипа (SVG) запрашиваются у заказчика до этапа 1; до их получения в макетах используются файлы выше.

## Корпоративные цвета

Базовые цвета — с карточек заказчика (`teta_info/корпоративные цвета.jpg`): **графитовый `#4A4A4A`**, **фиолетовый `#4D427A`**, **белый `#FFFFFF`**. Разрешены их варианты — светлые и тёмные оттенки из шкалы ниже.

| Шаг | Фиолетовый | Графитовый | Типовое применение |
|---|---|---|---|
| 50 | `#F4F4F7` | `#F4F4F4` | Фон страниц и кабинетов |
| 100 | `#E6E5EC` | `#E6E6E6` | Фон карточек второго уровня, выбранная строка |
| 200 | `#CDCADA` | `#CCCCCC` | Границы, разделители |
| 300 | `#AAA4BF` | `#A8A8A8` | Неактивные элементы, плейсхолдеры |
| 400 | `#7B739D` | `#797979` | Второстепенный текст на светлом фоне (только крупный текст) |
| **500** | **`#4D427A`** | **`#4A4A4A`** | Основные кнопки, акценты, заголовки; основной текст — графитовый |
| 600 | `#3F3664` | `#3D3D3D` | Наведение на кнопку |
| 700 | `#332C51` | `#313131` | Нажатие, тёмные плашки |
| 800 | `#25203B` | `#242424` | Фон тёмной темы: поверхности |
| 900 | `#191527` | `#181818` | Фон тёмной темы: основание |

Цвета из PDF фирменного стиля (`#423670`, `#564792`, `#2E254E`, `#6D5CB0`) допускается использовать как оттенки фиолетового. Семантические цвета (успех, предупреждение, ошибка) подбираются на этапе 1 в дизайн-системе и не заменяют корпоративные.

## Шрифт

**Onest** — единственный шрифт платформы: заголовки, текст, интерфейсы, email-письма, документы, презентации. Файлы шрифта подключаются с серверов проекта, без загрузки со сторонних CDN. Staatliches, Alata, Oswald и Jost не используются.

## Стиль

Дружелюбный минимализм на основе стиля teta.su (ТЗ v2, п. 5.4). Визуальный дизайн и фотографии прототипа test.teta.su — референс для дизайна фронтенда (Q-37).
