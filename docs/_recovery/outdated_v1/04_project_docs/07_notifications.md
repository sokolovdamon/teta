## 1. Принципы

| № | Принцип | Основание |
|---|---|---|
| 1 | **Транзакционные** уведомления (запись, оплата, безопасность, изменения по сессии) отправляются всегда; **сервисные** (напоминания, рекомендации, новости для психологов) — можно отключить; **маркетинговые** — только при действующем согласии, с отпиской в один клик | BR-NOTIF-01, 38-ФЗ ст. 18 |
| 2 | В теме и тексте писем нет тем запросов, диагнозов, содержания сессий; формулировки нейтральные: «Напоминание о встрече 16.09 в 21:00 (МСК)» | BR-NOTIF-03 |
| 3 | Время — в часовом поясе получателя с указанием пояса | BR-NOTIF-04 |
| 4 | Каналы MVP: **email** (DashaMail transactional) и **центр уведомлений** в кабинетах (CL-14, PRO-02). *R2:* Telegram-бот, web-push (PWA) | ТЗ п. 4, Q-23 |
| 5 | Транзакционные и маркетинговые письма отправляются с разных поддоменов (репутация доставляемости) | research B4 |
| 6 | Маркетинговые сегменты не используют темы запросов, дневник, анкету | [Рек.], 152-ФЗ |
| 7 | Промо-блоки не добавляются в транзакционные письма — иначе письмо становится рекламой | research A6.2 |
| 8 | Каждое письмо: логотип тенанта, обращение по имени/псевдониму, одно главное действие, футер с поддержкой, ссылкой «Экстренная помощь», реквизитами | ДНК, BR-CRISIS-02 |
| 9 | Тон — спокойный, бережный, без давления и восклицательных призывов | ДНК «характер бренда» |
| 10 | Все шаблоны и тайминги редактируются в ADM-11; все отправки журналируются со статусом доставки | ТЗ п. 7 |

**Обозначения:** Тип — **Т** транзакционное · **С** сервисное (отключаемое) · **М** маркетинговое (только с согласием). Канал — ✉ email · 🔔 центр уведомлений.

## 6. Структура транзакционного письма

| Часть | Содержимое |
|---|---|
| Тема | Нейтральная, без упоминания психологии в теме для писем о сессиях: «Встреча 16.09 в 21:00 (МСК) подтверждена» |
| Прехедер | Главное действие одной строкой |
| Шапка | Логотип тенанта |
| Текст | Обращение → факт → что это значит для получателя → одно главное действие |
| Детали | Таблица «когда / с кем / сколько / что дальше» |
| Футер | Поддержка · «Экстренная помощь» · центр уведомлений и отписка (для С и М) · реквизиты · «письмо отправлено автоматически» |
