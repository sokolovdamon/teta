## 4. Качество и сообщество

| Термин | Определение |
|---|---|
| Отбор психологов | Многоэтапная проверка кандидатов: документы → собеседование → тестовая сессия → решение; целевой уровень «1 из 20» (ДНК) |
| Супервизия | Профессиональный разбор практики психолога с более опытным специалистом |

| Модерация / премодерация | Проверка контента администратором до публикации (статьи, отзывы, профили, видео) |
| Этический кодекс | Правила профессионального поведения психологов ТЕТА |
| Кризисный протокол | Порядок действий при признаках угрозы жизни клиента |
| Кризисный флаг | Отметка о признаках риска из анкеты, диалога с Германом или от психолога |
| Контроль качества | Система показателей психолога: приватные оценки, удержание клиентов, инциденты, жалобы |

## 10. Словарь интерфейса: как говорим и как не говорим

| Не используем | Используем | Почему |
|---|---|---|
| пациент | клиент, вы | Немедицинская услуга (Q-26) |
| врач, доктор | психолог, специалист | То же |
| лечение, вылечить, диагноз | консультация, работа с психологом, запрос | То же; 38-ФЗ |
| приём, сеанс | сессия, встреча | Тон ДНК |
| штраф (для психологов) | инцидент, правило | Риск переквалификации в трудовые отношения |
| «деньги сгорят» | «оплата не возвращается по правилам…» | Бережность и точность |
| «срочно», «последний шанс» | спокойные формулировки | Характер бренда: спокойный, надёжный, бережный |
| рейтинг психолога, звёзды | отзывы, причины рекомендации | Бриф 8.4 |
| «TETA» в тексте | «ТЕТА» | Единое написание |
