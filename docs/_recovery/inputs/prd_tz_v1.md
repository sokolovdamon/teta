ТЕХНИЧЕСКОЕ ЗАДАНИЕ
на разработку сервиса онлайн-психологии

1. Название и суть проекта
Сервис онлайн-психологии нового поколения для проведения онлайн-сессий с психологами, автоматизации записи, проведения сеансов, выплат и аналитики, с уникальными функциями для сопровождения пользователей и продвижения психологов.

2. Цели сервиса
Для пользователей:
— Подбор психолога по анкете и фильтрам.
— Удобное бронирование и оплата сессий через подписку (разовое добавление карты, автоматическое списание за 12 часов до сессии).
— Проведение видеосессий онлайн.
— Одностороннее сопровождение через рекомендации и дневники эмоций без канала связи с психологом вне сессий.
Для психологов:
— Гибкое управление графиком.
— Удобное ведение базы клиентов.
— Публикация собственных статей с автопостингом на Дзен проекта ТЕТА.
Для владельца:
— Управление пользователями и психологами.
— Автоматизация выплат и аналитика.
— Укрепление SEO за счёт авторского контента.

3. Основные роли
— Клиент
— Психолог
— Администратор

4. Функционал клиентской части
— Регистрация по Email с подтверждением.
— Анкетирование для выявления потребностей. Вторая опция — общение с AI-ботом Германом.
— Подбор психолога автоматически или вручную.
— Просмотр профилей психологов (опыт, стоимость, отзывы).
— Бронирование доступных слотов.
— Оплата через КлаудКассир.
— Проведение видеосессий (WebRTC/Jitsi).
— Возможность смены психолога и повторного анкетирования.
— Уведомления и напоминания по Email с возможностью настройки сценариев автоматической отправки рекламных и маркетинговых материалов и уведомлений.
— Чат поддержки через Jivo.

5. Функционал кабинета психолога
— Регистрация и подтверждение квалификации.
— Заполнение профиля.
— Настройка графика и отпусков.
— Ведение карточек клиентов и заметок.
— Проведение видеосессий.
— Просмотр статистики и дохода.
— Управление автоматическим выводом средств на карту СЗ.
— Уведомления о записях по Email.
— Доступ к базе знаний и разделу Интервизии.
— Возможность публикации собственных статей на портале после премодерации.

6. Уникальные функции платформы
6.1. Внутренние «Дневники эмоций» — пользователь отмечает эмоциональное состояние при входе в ЛК. Психолог видит динамику состояния клиента.
6.2. Персональные рекомендации после сессий — психолог прикрепляет задания и упражнения.
6.3. Доступ к базе знаний для психологов — доступ к материалам (психологические техники, тесты, медитации, тексты аутотренингов).
6.4. Публикация статей на портале и автопостинг на «Яндекс Дзен» — экспертные материалы психологов, укрепление SEO платформы.
6.5. White-label B2B — внедрение функционала сервиса для стороннего партнёра. Партнёр может добавлять своих психологов, добавить своё название и т. д.

7. Административная панель
— Управление пользователями и психологами.
— Премодерация публикаций, статей и отзывов.
— Просмотр финансовой аналитики.
— Настройка выплат и уведомлений.
— Выгрузка отчётов по заданным фильтрам.

8. Технологический стек
— Frontend: Vue/React SPA, PWA.
— Backend: Node.js (NestJS/Express).
— БД: PostgreSQL/MongoDB.
— Видеосвязь: WebRTC/Jitsi.
— Платежи: КлаудКассир.
— Уведомления: Email.
— SEO: SSR/Prerender.

9. Дизайн-проект
— Разработка уникального дизайна основного сайта проекта с использованием корпоративного стиля, корпоративного шрифта, логотипа, фото- и видеоматериалов Заказчика.
— Разработка дизайна личного кабинета пользователя с использованием корпоративного стиля, корпоративного шрифта, логотипа.
— Разработка дизайна личного кабинета психолога с использованием корпоративного стиля, корпоративного шрифта, логотипа.
— Разработка дизайна административной панели владельца ресурса с использованием корпоративного стиля, корпоративного шрифта, логотипа.

10. Возможности масштабирования
— Корпоративные тарифы для HR. Регистрация сотрудника на портале лично, оплата организацией за проведённые сессии.
— Групповые вебинары, курсы, которые ведут психологи проекта для психологов проекта. Вебинары и прямые эфиры для клиентов.
— Сообщество психологов (Интервизия). Возможность начать ветку обсуждения и под ней писать экспертные комментарии для коллег.
— Интеграция с Apple Health / Google Fit.

11. Этапы разработки со сроками
Этап 1 (недели 1—3): Проектирование и дизайн
— Проработка CJM, wireframes.
— Создание дизайна лендинга, кабинета клиента, кабинета психолога, админки.
— Согласование с Заказчиком.
Этап 2 (недели 2—3): Бэкенд (базовый функционал)
— Настройка окружения.
— Реализация регистрации, аутентификации, ролей.
— Настройка базы данных.
Этап 3 (недели 4—7): Фронтенд (базовый функционал)
— Реализация личных кабинетов и расписания.
— Интеграция платежей и бронирования.
Этап 4 (недели 8—11): Видеозвонки, дневники эмоций, рекомендации
— Интеграция видеозвонков.
— Реализация дневников эмоций.
— Реализация рекомендаций после сессий.
Этап 5 (недели 12—13): Админка, тестирование и запуск
— Разработка административной панели.
— Тестирование всех модулей.
— Исправление багов.
— Подготовка к деплою.
