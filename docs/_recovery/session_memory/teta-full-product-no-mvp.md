Describe the TETA platform as one complete product. Do not split scope into MVP / R2 / R3 or "later" releases; organize work by the stages of the contract TZ (docs/01_inputs/tz_v2.md: Ядро, Этапы 1–11, сквозные задачи). Items the TZ lists as outside the contract (п. 11.1: corporate HR tariffs, webinars/courses) are still described as product features, marked "по отдельному соглашению".

**Why:** on 2026-09-11 the user explicitly said «Не мысли категориями MVP, описываем сразу полноценный продукт» after reviewing v1 docs that used MVP/R2/R3 everywhere.

**How to apply:** no release tags or "not in MVP" tables in any TETA doc, spreadsheet, mindmap or overview page; use a «Этап ТЗ» column instead. Related: [[teta-v2-decisions]].
